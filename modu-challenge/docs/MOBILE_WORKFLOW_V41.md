# v41 모바일 활동 카드 및 진행 안내

- 공식 브랜드 모두의클리어, 내부 URL/DB/인증 식별자 유지. 데이터 마이그레이션 없음.
- 활동 카드: 제목, 개별 상태 배지, 제안문, 보상금/날짜 분리. 600px 이하 2열 헤더와 전체 폭 본문, 359px 이하 버튼 세로 정렬.
- 개인 티저 SHORTLISTED는 `후보선정 완료`, SELECTED는 `최종 수행자 확정`. 미션 전체 상태와 개인 티저 상태를 구분.
- 여러 후보를 비교한 뒤 의뢰자가 최종 수행자 1명을 확정. 후보선정은 지급 확정이 아님.
- 미션 상세 상단에 현재 단계, 담당자, 다음 행동 및 이용 불가 사유 표시. 내 티저와 내 도전 목록에서 진행상황 접근 가능.
- 최종 확정 성공 시 후보 목록 대신 상세 진행 화면으로 이동.
- 단계: 공개 → 티저 → 후보선정 → 의뢰자의 보상금 확보 → 선정자의 수행/증빙 제출 → 의뢰자의 검수/완료 확정 → 지급 처리.
- SUCCESS와 실제 PAID를 구분. 취소/실패/분쟁 미션의 단계가 전부 완료로 표시되지 않음.
- 지급 콜백은 SUCCESS 미션의 PROCESSING/FAILED 정산만 변경 가능. FUNDED 단계에서 조기 지급 완료 처리 차단.

## 검증 범위

정적 검사 50개, 동작 회귀 검사 88개. 별도 SQLite에서 두 명의 독립 도전자, 후보 카운트, 단일 최종 선정, 역할 권한, 확보 전 증빙 차단, 결과 제출, 검수, 지급 콜백 및 중복 처리 검증. Google/Naver/이메일 기존 회귀는 외부 전송을 모의 처리함.

실제 PG/지급 제공사 연결은 준비되지 않았으므로 PUBLIC_MONEY_ENABLED=false 유지. APP_ENV=test에서만 후속 흐름 검증. 이를 운영 결제/실제 입금 성공으로 보고하지 않음. 실제 휴대폰/PWA 설치 및 모든 모바일 해상도 렌더링은 별도 확인 필요.
