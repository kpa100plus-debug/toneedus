## 개발 완료 범위
1. 운영환경은 VERIFICATION_ENFORCEMENT 값이 advisory여도 인증 필수. 관리자도 신규 의뢰·도전·후보선정 우회 불가. 만료된 수행자 재선정·제안 수정 차단.
2. 가입/소셜 이메일 인증/기존 identity_verified 플래그는 본인확인 근거로 인정하지 않음. 원본 DB 값은 보존하고 외부 인증 배지로 표시하지 않음.
3. PortOne V2 본인확인 시작/서버 재조회 경로: 세션에 요청 ID 귀속, 동의 버전·10분 제한·시간당 5회, 이름/전화 대조, 성인 확인, DI HMAC·고유제약, 1년 재확인, 중복·다른 계정 결과·만료 차단. CI/DI 원문 저장 안 함. SDK 시작·리다이렉트 복귀 경로 포함. 실제 키·기관 창은 미검증.
4. 최고관리자 인증 심사 목록·거절·철회·재확인 요청 및 감사기록. 관리자 단독 조작으로 기관 인증 완료 처리 불가. 사업자/법인/단체 검증은 PROVIDER_REQUIRED로 유지.
5. 별도 transaction_orders/events/ledger: 테스트 환경만 허용. 역할 검증, 10% 수수료, 원 단위 금액, 전액 환불, 취소, 검수·지급 상태 분리, 분쟁 보류, 실패 후 조사·재승인, 요청 멱등성, 버전 충돌, 제공사 거래번호 고유제약, 원장/이벤트 변경·삭제 금지. TEST 데이터는 기존 실거래 정산과 분리.
6. 운영 실거래 어댑터는 코드 수준 미개방. PUBLIC_MONEY_ENABLED=true로 바꾸어도 기존 수동 결제 확인 경로가 live로 바뀌지 않음. /api/transactions 쓰기 차단, 실제 거래내역 본인조회 경로 추가.
7. 예시 카드에 실제 지급완료처럼 보이던 문구를 '예시 · 실제 결제·지급 없음'으로 수정. 현재 기능 범위·취소/환불/분쟁 원칙·수수료 및 미확정 항목 고지.
8. PWA 등록 URL/매니페스트/자산/캐시 v53 통일. wrangler 설정 기준 동기화 스크립트 추가.

## 백업과 데이터 보존
배포는 다음 순서만 허용한다: 전체 D1 export → AES-256 CMS 암호화 → 암호화 산출물 보존 → 회원/미션/관리자 식별·귀속 해시 기록 → 추가 테이블 마이그레이션 → 동일 해시 대조 → Worker 배포.
공개 저장소에 SQL 원문·이메일 명단·개인키·API 키를 올리지 않는다. 공개 인증서만 소스에 포함된다. 별도로 보존한 MODUCLEAR-backup-recovery-key.pem이 있어야 암호화 백업을 복원할 수 있다.
GitHub 백업 artifact 보존은 90일. 실제 artifact 생성 성공과 데이터 대조 결과는 해당 배포 Actions 로그가 증거다. 복구는 신규 비운영 DB에서 해독·무결성 검증 후 별도 판단하며 자동 덮어쓰기하지 않는다.

## 검증 범위 및 한계
- 기존 동작/권한/가상 거래/DOM 회귀 112건 통과.
- 신규 인증·거래 12개 시험군: 기관 응답은 mock. 가입→양측 기관검증→등록/신청→만료 차단 및 별도 테스트 원장의 결제→수행→검수→지급/실패복구, 환불·분쟁·중복요청 검증.
- 실제 기관, PG, 지급업체 sandbox 호출 및 소액 실거래는 미수행. mock을 업체 승인시험으로 간주하지 않는다.
- 데스크톱 운영 브라우저 확인과 Galaxy 실제 기기·PWA 설치/오프라인·기관 앱 전환 검증은 다르다. 실기기 확인이 없으면 통과로 표시하지 않는다.
- 신규 거래 원장은 외부 제공사와 연결되지 않은 개발 기반이며 운영 미션의 실제 입금·지급 처리기로 사용하면 안 된다. 키만 입력하면 실거래가 완성되는 상태가 아니다.
