- 초기 공개화면과 계정조회 오류를 분리하고 재시도를 제공한다.
- 고액 보상금 위험점수를 제거하고 등록·수정·Cron에 같은 검수 규칙을 적용한다.
- 일반 API에서 내부 위험점수·탐지코드·원문 근거를 제거하고 수정안내만 반환한다.
- 이메일 링크·OAuth·재설정 토큰의 단일 사용, 세션 만료, 계정 연결 및 요청 제한을 보강한다.
- 링크 공개 미션의 직접 열람을 허용하고 비공개 미션·타인 TEASER 접근을 차단한다.
- 본인확인 중복·만료·취소 처리, 공개 인증정보 최소화, 사업자 자동조회 조건을 보강한다.
- 가상 부분환불·잔액 정산을 추가한다. 실제 금전 기능과 공급자 부분환불 전송은 비활성 상태다.

## 배포 보호

운영 전체 D1을 내보내 복원·무결성을 검사하고 기존 수신키로 암호화하여 아티팩트로 보존한다. 이후에만 마이그레이션과 Worker 배포가 실행된다. 기존 회원·미션·활동·인증·TRUST·관리자 권한·거래기록은 개인정보를 공개하지 않는 HMAC 증거로 전후 대조한다. 실패하면 후속 배포를 중단한다.

## 검증 경계

자동검사는 격리 SQLite 및 공급자 모의응답을 포함한다. 실제 외부 로그인, 메일 수신, 실명확인, PG 승인, 계좌확인 및 지급 성공을 의미하지 않는다. 운영 화면/API 확인과 실제 기기 검사는 별도 결과로 보고한다. 현재 작업 환경에서는 로컬 HTTP 서버 연결 및 로컬 파일의 브라우저 열기가 제한되어 배포 전 실브라우저 반응형 검증을 완료하지 못했다. 이를 통과로 기록하지 않는다.

외부 연결에 필요한 설정과 남은 실서비스 시험은 `EXTERNAL_PROVIDER_SETUP_20260927.md`를 참조한다. `PUBLIC_MONEY_ENABLED=false`, `moneyEnabled=false`, `moneyMode=disabled`를 유지한다.
