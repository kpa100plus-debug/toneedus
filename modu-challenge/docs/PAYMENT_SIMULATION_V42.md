# 모두의클리어 v42 — 모의 결제·지급

## 이용

1. 로그인 → 내 클리어 → 가상 결제·지급 테스트 (`/#/simulation`).
2. 새 가상 거래 생성(기본 10만원), 또는 본인 미션 상세에서 ‘가상 거래로 복제해 테스트’.
3. 수행자 역할: 가상 티저 2건 접수.
4. 의뢰자 역할: 후보 1명 이상 선정 → 최종 수행자 1명 확정.
5. 모의 결제창: 실패·취소 후 재시도, 또는 승인 → 보상금 확보.
6. 수행자 역할: 결과 20자 이상 작성 → 제출.
7. 의뢰자 역할: 보완 요청 또는 검수 완료.
8. 가상 지급 실패 → 재시도, 또는 가상 지급 완료.
9. 실제 거래금액은 항상 0원. 테스트 금액 10만원이면 수수료 1만원, 가상 수령액 9만원.

승인 후 검수 완료 전에는 전액 환불 테스트 가능. 지급 완료 후에는 중복 지급/환불 금지. 결제 전 가상 미션 취소 가능. 새로고침·재로그인 후 본인 테스트 거래 목록으로 복귀.

## 격리 및 보안

- `payment_simulations` 신규 테이블만 사용. 기존 DB/회원/미션/티저/정산 데이터 변경·삭제 없음.
- 실 결제 설정 `PUBLIC_MONEY_ENABLED=false` 유지. 모의 API는 기존 결제·지급 API를 활성화하지 않음.
- 자체 가상 거래 제공자이며 외부 PG의 공식 샌드박스가 아님. 카드·계좌·송금·실제 청구·외부 알림 없음.
- 본인 세션으로만 읽기/쓰기. 실제 회원 권한과 무관한 가상 역할 전환 기능. 다른 회원의 테스트 거래 열람 불가.
- 원본 미션 복제는 의뢰자 또는 관리자에게만 허용. 원본 금액/성공조건은 서버에서 읽고, 기존 참가자 정보를 복제하지 않음.
- 모든 변경은 요청 식별자/버전 검사 및 DB compare-and-swap으로 중복·동시 실행 방지.
- 거래별 150 이벤트, 계정별 100 거래 제한. 테스트 데이터는 실제 신뢰도·매출·성과·보상 통계에 합산되지 않음.

## 검사

기존 기능 회귀에 가상 결제/실패/취소/환불/검수/지급/권한/중복/동시 요청/표시 검사를 추가. 테스트 수행 전후 실제 테이블의 모든 행이 동일함을 비교. 물리적 Galaxy/PWA 설치와 외부 PG/은행 연동은 이번 모의 기능의 검증 대상이 아님.
